# 📋 Smart Project Tracker

A simple Python-based project management tool to manage and track tasks.

## 🚀 Features

- Add tasks
- View tasks
- Delete tasks
- Mark tasks as completed
- Track project progress
- Show completed and pending tasks

## 🛠️ Technologies

- Python
- Git
- GitHub

## ▶️ How to Run

```bash
python app.py
```
